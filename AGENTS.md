- Утверждённые тексты и параметры: metadata/policy.json. Не добавлять публичные фразы от себя.
- Оригинальные изображения и GIF не менять, не сжимать и не перерисовывать.
- Готовые 10000 PNG и 454 исходных слоя сохранять; приватные материалы не публиковать до раскрытия.
- До раскрытия скрытые metadata не содержат атрибутов, рангов и процентов. Раскрытие не раньше 2027-01-01.
- Продажи закрыты. Не открывать их без нового указания владельца.
- Сайт публикуется через GitHub Pages. Сохранять собранные wallet-standard.js, LEGAL.txt и все 10000 metadata/hidden/*.json для обеих схем публикации.
- После изменения сайта: npm run build:wallet, npm run build:site, npm run verify. Проверять сохранность оригиналов и ссылок.
