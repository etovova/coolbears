# CoolBears — дополнения к RPC и кошелькам, 22 сентября 2026

Подготовлены на основе опубликованной версии e0c84febcc503ce16a0b9359588b00f53ef809a0. Владелец явно разрешил публикацию 22 сентября 2026. Эти дополнения пока не опубликованы: повторный git push остановился из-за отсутствия авторизации HTTPS, а подключение GitHub в чате вернуло HTTP 400 «Invalid MCP request metadata». Это техническая ошибка доступа; повторное разрешение владельца не требуется. Свежий fetch подтвердил прежний main e0c84febcc503ce16a0b9359588b00f53ef809a0.

## Что изменено

- Backpack: отдельная кнопка тестового подключения и официальные ссылки открытия приложения на основной и тестовой страницах. Подпись использует Wallet Standard с проверкой Devnet, v0 и возможностей аккаунта.
- RPC: последовательные запросы с интервалом не менее 250 мс; сохраняются ограниченные повторы, Retry-After, общий тайм-аут и журнал неопределённой операции. Ключ RPC не сохраняется в ссылках и журнале.
- Ссылки открытия приложений исключают логин, пароль, фрагменты и посторонние параметры URL; сохраняется только утверждённая подсказка выбора кошелька.
- Подготовлен автоматический запуск сценариев в Chromium, Firefox и WebKit через GitHub Actions; он ещё не выполнен, поскольку отправка ветки не прошла авторизацию.
