Это не Mainnet, реальный кошелёк, консенсус или открытие продаж. Подписи нулевые, проверка подписей выключена, local blockhash checks включены. Default feature set LiteSVM не объявлен идентичным валидатору. Временные аккаунты нельзя переносить в production.
