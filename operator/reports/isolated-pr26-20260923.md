## Исправление, найденное при выполнении

SDK 0.3.0 hooked serializer принудительно записывал неправильный discriminator Guard, и прежние синтетические fixtures повторяли ошибку. Реальная программа создаёт официальный CandyGuard header. Проверка теперь использует официальный generated header + guard data serializer, сравнивает все байты и отвергает неверный старый prefix. Добавлен regression fixture из фактического выполнения Devnet binary. Параметры Guard не ослаблены.

## Границы результата и продолжение

Это изолированное выполнение с копиями Devnet-программ, искусственным балансом owner и публичными адресами без secret keys. Signature verification и duplicate-signature cache выключены, local blockhash verification включена. Default feature set и остальные sysvars LiteSVM не объявляются идентичными живому валидатору. Программные хеши относятся к исходному банку; после запуска binaries не перечитывались.

Mainnet, consensus/finality, реальные подписи владельца, включение транзакций, физические кошельки и marketplace не проверены. Production bundle не создан. `budgetComplete=false`, `fundingRecommendationLamports=null`. Будущие buyer mints, reveal, хостинг/хранение/домен/RPC-подписки и курс SOL не включены. Следующий этап должен отдельно закрывать оставшееся покрытие бюджета; нельзя просить пополнение на основании этой суммы или переносить временные адреса в настоящий выпуск.

Main остаётся 83db789fdd61ccf4f83d7f0642e355cc75523269 с опубликованной ценой 0.2; PR17–22, PR24–26 не слиты. Кошелёк пока не нужен. Mainnet, снятие AddressGate и открытие продаж требуют отдельного указания.
