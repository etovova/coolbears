# PR32: локальный owner signing console

Добавлен `operator/deployment/owner-console/`: prepare/serve/import-response,
loopback HTTP, Wallet Standard sign-only, повторная симуляция до кошелька,
независимая проверка bytes и durable запись ответа. Реальные keys/endpoint ещё
не установлены. Никаких новых live transactions, owner signatures или deployment.

Новые journal events `request-wallet` / `wallet-declined` сохраняют выдачу до
возврата bytes. Claim переживает смену вкладки/профиля и restart. Автоматически
по таймауту он не снимается. Только явный отказ доверенного локального UI
с code 4001 и точным claim ID освобождает выдачу; неизвестный исход сохраняется.
Старый код журнала не должен записывать историю с новыми событиями.

Подпись проверяется одним portable модулем и на клиенте, и на сервере. Для SHA256
явно закреплён @noble/hashes 1.8.0 (та же уже установленная транзитивная версия).
Все прежние 17 signing tests прошли локально. Новый тест использует настоящий
loopback HTTP и подменённые RPC/wallet; проверка HTTP уже прошла. Полная проверка
новых сценариев и независимый CI выполняются при сохранении этого checkpoint.

Chromium в текущем окружении не установился: загрузчик получил неполный архив.
Добавлен отдельный CI job с закреплённым Playwright 1.62.1 и настоящими DOM,
IndexedDB, локальным сервером и сохранением снимков desktop/mobile layout.
Это не реальные Phantom/Solflare и не физический телефон. Итог CI фиксируется
в описании PR и актуальном файле `CoolBears_Collection(1).md`.

Следующее после зелёных проверок: реальная приватная настройка custody и отдельного
RPC. Пароль вводится только в локальном терминале; его и ключи нельзя просить
в чате. Desktop loopback не является мобильным deeplink. Sender, отдельный
публичный buyer RPC и полный пользовательский процесс ещё не завершены.
Основной сайт, DNS, существующий лабораторный Worker, оригиналы и Helius-тариф
не меняются. Продажи закрыты, Mainnet и новые реальные транзакции не выполняются.

Инструкция и границы: [owner-console README](../deployment/owner-console/README.md).
