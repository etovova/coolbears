# Предварительный расчёт в Devnet без кошелька

Этот этап продолжает PR24 с ценой 0,2 SOL. Он не создаёт production-bundle или ключи, не обращается к завершённой лаборатории и не меняет Helius/Cloudflare. Продажи закрыты.

Из корня репозитория после установки закреплённых зависимостей и operator setup:

```bash
node operator/deployment/preview-cli.mjs
```

Команда явно использует официальный публичный https://api.devnet.solana.com. Проверяет Devnet genesis, программы и отсутствие аккаунтов по случайным публичным адресам-заглушкам. Приватные ключи для них не создаются. Эти адреса нельзя переносить в production-bundle.

Полный canonical SDK-план содержит collection, reserve #0000, machine/guard и 9999 строк. Размеры берутся из существующей модели PR22. Rent читается из сети для всех пяти размеров и повторно сравнивается в конце. Каждое сообщение получает собственный getFeeForMessage; нет экстраполяции комиссии одной вставки на все остальные.

Публичный endpoint имеет ограничения: официальный справочник указывает 40 запросов одного метода за 10 секунд, и лимиты могут меняться. Запросы последовательные, между началами не менее 350 мс; при 429 или другой ошибке нет автоматического повтора или переключения провайдера. Поэтому полный расчёт занимает примерно 10 минут. Группы до 24 сообщений получают свежий blockhash; каждая группа заканчивается проверкой его валидности и высоты. Исходные bytes не меняются.

Это **неатомарная оценка по последовательным временным окнам**: все комиссии наблюдались в сети, но не одновременно. Флаги allQuotesSimultaneouslyFresh=false, budgetComplete=false и fundingRecommendationLamports=null сохраняются. Проверка реального production-bundle и свежий бюджет PR22 перед подписью обязательны. Devnet-оценка не является ценой запуска Mainnet.

Перед котировками запускается существующая unsigned-симуляция только collection-create на временном локальном журнале. Подпись владельца не нужна; sigVerify=false, replaceRecentBlockhash=false. Ошибка/недостаточный баланс сохраняются как отдельный результат, а не успешная симуляция. Зависимые операции не симулируются, поскольку первый simulateTransaction не сохраняет коллекцию в сети. wholeDeploymentSimulated=false. Кошелёк, faucet и отправитель отсутствуют.

Итоговый JSON записывается в build/devnet-cost-preview.json без перезаписи существующего отчёта. Он содержит отдельно rent, protocol fee по модели, все message hashes/fees и временные окна, базовую сумму, сценарий запаса 10% и десяти повторов. Запас не является разрешением повтора. Затраты будущих покупателей, раскрытие, hosting/storage/domain/RPC subscriptions и курс SOL не входят в новый deployment.

GitHub выполняет эту проверку отдельным job только для веток deployment-preview-* в этом же репозитории и после успешных операторских тестов. Job имеет только contents:read, не получает API-ключи и не публикует сайт. Внешняя сеть проверяется отдельно от детерминированных unit-тестов. Ошибка RPC делает сетевой job неуспешным; отчёт с причиной всё равно сохраняется.
