# Постоянное подключение CoolBears к Devnet

## Что подготовлено

Новый обработчик `rpc-proxy/` размещается отдельно от статического сайта GitHub Pages. Он хранит ключ Helius в серверном секрете и передаёт только разрешённые запросы к Solana Devnet. Страница получает публичный адрес обработчика без API-ключа. Подключение этого адреса к странице — следующий отдельный этап после проверки опубликованного Worker. На текущем этапе сайт остаётся на проверенной версии 6.

Это обработчик существующей лабораторной машины на две позиции. Он не подходит для публичных продаж или Mainnet без отдельного изменения политики и повторной проверки. Успешный минт владельца версии 6 уже подтверждён присланным отчётом и отображением NFT с анимацией. Для установки обработчика повторный минт не нужен.

В этой версии размещается только серверная часть. Настройка `siteRpc` и клиент версии 7 остаются в PR №16 и ещё не опубликованы: работающий сервер пока не подключён к сайту. Исходники и тесты сами по себе не означают, что новый RPC опубликован. Ключа Helius в репозитории нет.

## Проверки до размещения

```sh
npm ci --no-audit --no-fund
npm run test:devnet
npm run build:wallet
npm run build:site
npm run verify
npm run build:rpc
npm run test:rpc-runtime
```

`build:rpc` выполняет только dry-run, ничего не публикует. `test:rpc-runtime` запускает настоящий локальный workerd и SQLite Durable Object, но все обращения к Helius заменены фикстурами. Он не отправляет блокчейн-транзакции. GitHub Actions дополнительно проверяет сайт в Chromium, Firefox и WebKit с имитацией RPC/кошельков. Это не физические тесты всех устройств и не гарантия отсутствия ошибок у провайдера.

## Размещение после входа владельца в Cloudflare

Использовать аккаунт владельца с Workers и SQLite Durable Objects. Сначала проверить доступность бесплатных лимитов и отсутствие включённых платных дополнений. Платная подписка не требуется самим кодом и автоматически не подключается.

Через текущую форму Cloudflare «Set up your application»:

- Репозиторий `etovova/coolbears`, основная ветка `main` с серверными файлами.
- Project name: `coolbears-devnet-rpc`.
- Build command: пусто; Deploy command: `npx wrangler deploy --config rpc-proxy/wrangler.jsonc`.
- Path: `/`; Enable Preview builds: выключено.
- API token: Create new token, имя `coolbears-devnet-rpc-build`. Это токен Cloudflare для развёртывания.
- Build variables оставить пустыми. После первого Deploy добавить `HELIUS_API_KEY` как runtime Secret в настройках Worker, затем применить изменение. Сам ключ не отправлять в переписку.

Либо из доверенного терминала в корне репозитория:

```sh
npx wrangler login
npx wrangler secret put HELIUS_API_KEY --config rpc-proxy/wrangler.jsonc
npx wrangler deploy --config rpc-proxy/wrangler.jsonc
```

Ключ Helius вводится в запрос `secret put`, не в аргумент команды, файл сайта или переписку. Это API-ключ провайдера; приватный ключ кошелька здесь не используется. Если Cloudflare требует сначала создать Worker, создать его развёртыванием без секрета: обработчик будет отказывать запросам до установки секрета. Не менять имя `coolbears-devnet-rpc`, имя класса/объекта и существующие миграции при следующем обновлении: в хранилище остаются ограничения и доказательства прошлых отправок.

Полученный публичный URL должен оканчиваться `/rpc`, без ключа, query string или фрагмента. До изменения сайта выполнить проверку из подготовленной ветки `rpc-wallet-additions-shared-rpc-20260922` (PR №16), где находится скрипт проверки:

```sh
npm run check:site-rpc -- --endpoint https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/rpc
```

Заменить пример настоящим адресом. Команда проверяет CORS, заголовок `solana-client`, Devnet genesis и текущие аккаунты машины/guard/коллекции. Это только чтение: исчерпанный тестовый тираж допустим, подпись и новый минт не запрашиваются. При ошибке адрес в сайт не добавлять.

После успешной проверки в подготовленной клиентской ветке PR №16 записать этот публичный URL в `siteRpc` в `devnet/settings.mjs`, пересобрать `build:wallet` и `build:site`, выполнить `verify` и браузерные проверки. Затем опубликовать проверенный коммит сайта. На физическом телефоне достаточно открыть страницу, подключить Phantom и проверить уже сохранённый NFT; журнал операции не удалять.

## Ограничения и обслуживание

Квоты общие для всех посетителей, сохраняются в одном Durable Object и ограничивают только этот обработчик. Они не учитывают другие программы с тем же ключом Helius. По умолчанию разрешено не более 20 000 upstream-запросов за UTC-день; дополнительные ограничения описаны в [документации обработчика](../rpc-proxy/README.md). CORS не защищает от расходования квоты небраузерными клиентами. Бесплатные лимиты Cloudflare и Helius всё равно требуют наблюдения.

При 429/недоступности страница сохраняет состояние и допускает только ограниченные повторные чтения. Отправка новой транзакции не повторяется автоматически. Остановка платного тарифа RPC не удаляет уже выпущенные NFT; доступность изображений и анимации зависит от их собственного хранилища. Любое последующее изменение сети, машины, цены или формата транзакции требует отдельной проверки.
