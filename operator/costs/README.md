# Затраты на минт, раскрытие и внешние сервисы

Этап после PR26, 23 сентября 2026. Цена **0,2 SOL**, продажи закрыты.
Это расчёт и выполнение в памяти с публичными копиями Devnet-программ.
Реальные транзакции, кошелёк и production-ключи не используются.

```sh
npm ci --prefix operator --ignore-scripts --no-audit --no-fund
npm run --prefix operator setup
node operator/costs/cli.mjs
```

Команда читает только официальный публичный Devnet RPC. Результат и публичный
снимок программ сохраняются в `operator/build/lifecycle-costs/` с запретом
перезаписи. Для нового запуска прежнюю папку следует сохранить под другим именем.
GitHub Actions хранит её 14 дней; проверенный итог отдельно сохраняется в
`operator/reports/`. Настройки Helius/Cloudflare и опубликованный сайт не меняются.

## Что проверяется

1. Все 1431 операции подготовки PR26 выполняются заново только в искусственном
   банке. Проверяются полное состояние и все строки машины.
2. Обычная попытка покупателя через существующий шаблон заказа отклоняется
   `AddressGate` с `AddressNotAuthorized` (6033). NFT не создаётся, цена не
   перечисляется, аккаунты машины/коллекции/Guard неизменны. Измеряется комиссия
   за неуспешное выполнение, списанная в памяти.
3. Ровно 50 последовательных минтов используют существующий двухподписный
   шаблон заказа с разрешённым владельцем. Проверяются владельцы NFT, коллекция,
   скрытые имена/URI, отсутствие повторов в выборке, размер, rent, Core charge
   и комиссия каждого сообщения. Поскольку minter совпадает с treasury,
   платёж 0,2 SOL здесь возвращается самому отправителю; итог для обычного
   покупателя показан **проекцией**, а не успешным открытым минтом.
4. Дополнительный поддерживаемый SDK сценарий с разрешённым minter и отдельным
   плательщиком проверяет фактический перевод 200000000 lamports между двумя
   искусственными балансами и получение NFT плательщиком. У него три подписи,
   поэтому его комиссия на 5000 lamports выше стандартной. Guard не меняется.
5. Четыре различных NFT обновляются только в памяти: утверждённое раскрытое имя
   и синтетические URI домена `example.invalid` длиной 52/80/120/200 байт.
   Владельцы, коллекция и Core charge сохраняются; один NFT принадлежит отдельному
   плательщику, что проверяет полномочия update authority коллекции. Приватные
   работы, атрибуты, CID и реальная карта раскрытия не читаются и не публикуются.
6. После проверок Guard побайтно совпадает с исходным, конфигурация машины и
   политика/плагины коллекции сохранены. Счётчики увеличились ровно на 51.
7. Пять размеров аккаунтов и четыре формы сообщений сверяются со свежими
   read-only rent/fee quotes Devnet. Проверяются genesis, срок blockhash и
   неизменный Rent sysvar. Это не свежая проверка каждой комиссии подготовки.

Результаты содержат SHA-256 программ, снимка и сообщений. Пары NFT → случайно
выбранная запись машины не выводятся. Балансы и все новые адреса искусственные;
секретные ключи отсутствуют, подписи нулевые, проверка подписей выключена.
Локальные blockhash checks включены. Консенсус, включение в блок, Mainnet,
соответствие feature set валидатору и работа физического кошелька не подтверждены.

## Как читать суммы

Покупатель оплачивает цену, rent своего NFT, Core charge и сетевую комиссию.
В текущем измерении на NFT: 200000000 + 1452880 + 1500000 + 10000 =
**202962880 lamports (0,202962880 SOL)**. Это Devnet-калиброванный ориентир без
приоритетной комиссии. Суммы для 1/10/50 NFT считаются целыми lamports; один заказ
не означает одну транзакцию или одно окно подписи.

Раскрытие моделируется как одна транзакция обновления на каждый из 10000 NFT.
Фактическое количество обновлений зависит от наличия NFT; это сценарий полного
выпуска. Новый размер зависит от **байтовой длины** имени и URI. Рост требует
дополнительного rent; при уменьшении наблюдаемый возврат показан отдельно и не
уменьшает требуемые средства заранее. Возможное объединение обновлений в одной
транзакции не учтено. Реальное раскрытие не выполнено и не допускается раньше
2027-01-01. Поведение единственного полного сценария URI не считается известным,
пока финальный URI не определён.

| Длина URI, байт | Новый аккаунт, байт | Раскрытие 10000 NFT, SOL до возвратов |
| --- | --- | --- |
| 52 | 142 | 0,050000000 |
| 80 | 170 | 0,659600000 |
| 120 | 210 | 2,691600000 |
| 200 | 290 | 6,755600000 |

Это сценарии, **не нижняя и верхняя границы** всех возможных URI. При 52 байтах
наблюдаемый потенциальный возврат rent составляет 0,8128 SOL за 10000 обновлений,
но он не засчитывается как имеющийся баланс. К расходам владельца добавляются
подготовка из PR26, выбранный сценарий раскрытия и услуги. Расходы покупателей
не прибавляются к бюджету владельца. Выручка и возможные возвраты не используются
для обещания окупаемости или уменьшения суммы до запуска.

Приоритетная комиссия для v0: `ceil(CU_limit × microLamports_per_CU / 1000000)`.
Примеры для 300000 CU — арифметика, а не текущая рыночная рекомендация. Повторная
успешная попытка оплачивается заново; уже понесённая комиссия не исчезает.
Неопределённую транзакцию сначала сверяют с сетью, автоматического повтора нет.
Все разновидности отказов этим этапом не симулируются.

## Внешние услуги и незакрытые статьи

[services.json](services.json) фиксирует публичные тарифы на 23 сентября 2026,
ссылки, периоды оплаты и неизвестные значения. Реальные счета владельца и
выбранные тарифы не проверялись, подписки не менялись. Сценарии $20/$69/$74 в
месяц относятся только к комбинациям Pinata/Helius/Workers и исключают хостинг
сайта, домен, налоги и превышение лимитов. Домен показан отдельно за год.
Размер файлов и будущий трафик неизвестны; бесплатный тариф не считается
достаточным без проверки лимитов и фактической нагрузки.

Правила GitHub Pages ограничивают использование бесплатного хостинга для сайтов,
основная цель которых — коммерческие транзакции. Выбор подходящего хостинга и
его стоимость остаются вопросом до открытия продаж; текущий сайт не переносится.

`budgetComplete=false`, `fundingRecommendationLamports=null`: точную сумму
пополнения нельзя получить до Mainnet-калибровки, длины финального URI, выбора
хостинга, фактических счетов/нагрузки и запаса на комиссии/отказы. USD и SOL не
смешиваются без отдельного курса. Эти неизвестные статьи не подменяются нулём.
