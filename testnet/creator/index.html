Резерв создателя: тест

Новая версия с утверждённым описанием и резервом NFT №0 для твоего кошелька. Публичный минт закрыт, кроме времени отдельной проверки пакетного выпуска. Старая тестовая коллекция сохраняется.

Пакет развёртывания

1. Развернуть контракт

0,2 тестового TON плюс комиссия кошелька.

2. Получить зарезервированный NFT

7,10 тестового TON плюс комиссия кошелька. 7 TON направляются на настроенный адрес казначейства, 0,05 TON — на создание NFT; остаток покрывает расходы и остаётся в коллекции.

Этот шаг доступен только закреплённому кошельку. После выпуска повторный минт резерва блокируется. Публичный минт открывать не нужно.

Пакетный минт: ещё 2 NFT

Этот тест выполняется после резерва №0. После каждой подписи нажимай «Проверить состояние» и дожидайся подтверждения.



Плюс комиссия кошелька за каждую операцию. В 14,20 входят 14 TON цены, 0,10 TON для создания двух NFT и 0,10 TON запаса на расходы. Неиспользованный остаток остаётся в коллекции. Пока пауза снята, минт в этом testnet-контракте доступен также из других кошельков. После теста обязательно верни паузу. Кнопка пакетного теста доступна только при одном уже выпущенном NFT.

Проверяем право получения NFT. Финальные изображения ещё не сгенерированы, поэтому этот тестовый NFT показывает заглушку. Самый редкий медведь будет назначен при финальной генерации основной коллекции. Запрет раннего раскрытия: 1 января 2027 года, 00:00 UTC.
