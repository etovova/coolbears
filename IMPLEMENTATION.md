# CoolBears — issuance rebuild

The owner stopped and rejected the Core v2 owner workflow on 21 September 2026 after repeated mobile failures. The runtime, owner application, generated mint bundles and associated tests have been removed from the active website. `/manage/` is a static notice with no scripts or wallet actions. The main website has its closed prelaunch behavior.

Original artwork, layers, branding, approved descriptions, hidden metadata, private recovery packages and collection integrity tools are preserved. No chain accounts were deleted or re-created by this cleanup. Any existing wallet receipts must be reconciled before a future deployment.

The replacement is developed separately and must not be published as a working mint until its network and wallet flow are verified. Real network execution and mobile wallet signatures must be distinguished from VM and mocked tests. Public RPC retry loops are insufficient release validation. Use an account-owned RPC with an explicit deadline, show each operation, store signed bytes before broadcast and reconcile by the same transaction signature. Mainnet and sales remain closed.
