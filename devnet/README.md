# CoolBears: тест подписи кошелька

Страница `/devnet/` использует существующую лабораторную Core Candy Machine на две позиции. Это не публичная продажа и не полная коллекция. Основной сайт и `config.js` сохраняют закрытые продажи.

Владелец подтвердил, что GIF уже выпущенного NFT #0002 отображается. Это подтверждение отображения GIF по присланной ссылке, не результат физического теста подписи Phantom.

## Перед повторной попыткой владельца

Скриншот физического Phantom подтвердил подключение FNyt…CW6y и HTTP 429 от общего RPC. Сначала необходимо добиться успешной проверки RPC/состояния; не повторять подпись при неопределённой операции. Свежая read-only симуляция точного builder 22 сентября успешна, но использует другой сетевой путь и не доказывает доступ с телефона.

## Проверка владельцем

1. Открыть `https://coolbears-nfts.com/devnet/` в браузере Phantom или в браузере с расширением Phantom. Также предусмотрен Solflare и обнаруженные совместимые Wallet Standard кошельки; физические тесты этих кошельков ещё не проводились. В обычном мобильном браузере кнопка Phantom открывает страницу в приложении, если провайдер отсутствует.
2. Выбрать сеть Devnet и адрес FNytKprG3JukM81svBhCrgHAEHht3oUgpXZFUkUbCW6y.
3. Нажать «Подключить Phantom». Страница проверит сеть, программы аккаунтов, оставшийся тираж, получателя, цену и роялти.
4. Нажать «Выпустить тестовый NFT» и подтвердить одну транзакцию. До окна подписи выполняется реальная симуляция и сохраняются публичные координаты операции.
5. При задержке воспользоваться «Проверить результат». Эта кнопка только читает блокчейн, в том числе после перезагрузки. «Скачать результат проверки» сохраняет публичный журнал без приватных ключей.

Цена guard — 0,5 Devnet SOL; получателем является тот же кошелёк владельца. Дополнительно оплачиваются тестовые комиссии и хранение аккаунта NFT. Владелец не передаёт приложению свой приватный ключ.

## Устройство и проверенный объём

- Официальные Core SDK закреплены в `package-lock.json`. Сборка включает Buffer для зависимостей web3.js.
- Wallet Standard используется с явной сетью `solana:devnet`; для injected Phantom/Solflare применяется `signAndSendTransaction`. Сеть такого injected кошелька выбирает пользователь. Blockhash и все проверки приложения относятся только к Devnet.
- Приложение не вызывает RPC `sendTransaction`: кошелёк подписывает и отправляет один частично подписанный v0 mint. Ключ нового asset существует только в памяти подготовки; ключ плательщика никогда не запрашивается приложением.
- Публичный журнал записывается перед подписью. Web Locks не дают двум вкладкам начать отправку одновременно. Неопределённый результат запрещает новую попытку.
- Подтверждение — HTTPS polling до `finalized`, проверка `err`, программы Core, фактического владельца, коллекции, имени и URI. Положительного slot недостаточно.
- Истечение признаётся только после finalized blockhash expiry и повторной проверки отсутствия asset/подписи с контекстом не старее проверки expiry. После тайм-аута подпись не запрашивается повторно автоматически.
- Отказ кошелька с кодом 4001 позволяет новую попытку. Повторяются только чтения/симуляции при временных сетевых ошибках: не более трёх попыток, с паузой и соблюдением Retry-After. Ошибки доступа и некорректные ответы не повторяются. Окно ответа кошелька ограничено 60 секундами; поздняя подпись сохраняется и не затирается старым результатом проверки.
- Лимит одной попытки RPC — 25 секунд; общий срок запроса с очередью/повторами — 45 секунд; сетевой этап страницы — до 90 секунд. Очередь и число попыток ограничены. После истечения срока подпись не повторяется.
- Свой HTTPS RPC задаётся в закрываемом разделе страницы. Адрес/ключ сохраняется только в памяти до перезагрузки, не записывается в localStorage, журнал, диагностику или ссылки открытия кошелька. Сеть проверяется по genesis hash до чтения аккаунтов. При неверной сети минт заблокирован. Публичный RPC остаётся общим и может продолжать отвечать 429; выделенный доступ провайдера не был создан.
- Заблокированное/повреждённое localStorage запрещает минт до сохранения операции; экспорт диагностики доступен даже при запрете доступа к storage. Публичный журнал неопределённой операции не очищается автоматически.
- `npm run test:devnet` включает протоколы RPC/Wallet Standard, частичную подпись, журнал и recovery. `tests/devnet.browser.mjs` и `tests/devnet-matrix.browser.mjs` проверяют браузерную связку с имитацией RPC/кошелька. `tests/main.browser.mjs` — основной сайт, языки, калькулятор и подключение. Отчёты сохраняют фактический объём и ограничения; эмуляция viewport/UA/touch не является проверкой реального телефона.


Реальный отчёт `operator/reports/wallet-test-preflight.json`: точный браузерный builder успешно симулирован; другой minter отклонён `AddressNotAuthorized` 6033. Проверка подписей в этой симуляции выключена, поскольку подпись владельца доступна только в его кошельке. Новых NFT во время проверки не создавали.

## Изменение существующего guard

`operator/prepare-wallet-test.mjs` один раз изменил addressGate с лабораторного плательщика Bjst…qyF на владельца FNyt…CW6y. Цена, получатель и остальные guards сохранены; machine/collection не пересоздавались. Подпись `3npVtuiFhsG78wTCcRTAeGxpzWnBfua4wFE2GcJ9wDDYKtft7Dc4a41BMLR4CdbqNRN1dEw2iQdz3pGDmiBY7ctv`, finalized slot 502144728. Приватный журнал `05-wallet-gate` не удалять и не повторять.

Старые отчёты о закрытии guard для FNyt описывают состояние до этой транзакции. Старый `verify-lab-mint.mjs` проверяет именно предыдущий guard; для текущего состояния использовать новый read-only `readState`/`inspectOperation` из `devnet/core.mjs`. Сам NFT #0002 и его подпись не менялись.
