# CoolBears

Сайт: https://coolbears-nfts.com

Основной сайт и оригинальные изображения. Утверждённые описания и параметры: `metadata/policy.json`.

Сборка: `npm ci`, `npm ci --prefix release --omit=dev --ignore-scripts`, `npm run build:wallet`, `npm run build:site`, `npm run verify`.

Отдельная проверка Phantom в Devnet: `/phantom-check/`. Код и область выполненных проверок описаны в `release/README.md`. Проверка на физическом кошельке владельца пока ожидается.

Продажи закрыты. Прежний механизм выпуска, страницы управления и просмотра, тесты, загрузчики и связанные зависимости удалены. Приватные материалы коллекции хранятся отдельно.
