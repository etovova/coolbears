# Подготовленный вариант хостинга CoolBears

Этап PR28 после расчётов PR27. **Цена 0,2 SOL, продажи закрыты.**
Рекомендуемый технический вариант — отдельный **Cloudflare Workers Static
Assets** для существующего сайта. Справочная цена статической части — **$0/мес**:
хранение Assets и запросы, обслуженные статическими файлами, не тарифицируются.
RPC, домен и финальное хранилище NFT считаются отдельно. Это предложение,
аккаунт хостинга/тариф не менялся и новый сайт не опубликован.

## Что подготовлено

Команды из корня репозитория после установки закреплённых зависимостей:

```sh
npm run build:wallet
npm run build:site
npm run verify
node --test hosting/audit.test.mjs
node hosting/prepare.mjs
node hosting/runtime.mjs
WRANGLER_SEND_METRICS=false CLOUDFLARE_SEND_METRICS=false node node_modules/wrangler/bin/wrangler.js deploy --config build/hosting-candidate/wrangler.json --dry-run --outdir build/hosting-dry-run
```

`--dry-run` обязателен для этой проверки: загрузка не выполняется.
`prepare.mjs` создаёт новую папку `build/hosting-candidate/`; прежний результат
не перезаписывается. Перед повтором его сохраняют под другим именем. Внутри:
`site/`, переносимый `wrangler.json`, `report.json`, затем `runtime.json`.
GitHub Actions сохраняет проверенный пакет на 14 дней. Код подготовки и
постоянный отчёт остаются в Git. Ключи, секреты или wallet bundle не нужны.

Пакет содержит 10031 существующий публичный файл и один служебный `_headers`.
Размер — **11146096 байт**, крупнейший файл — **1504057 байт**. Проверяется
точное совпадение каждого публичного файла с исходником и всех 10000 скрытых
JSON с утверждённой моделью. Оригинальные GIF/лого/баннер дополнительно сверяются
с сохранёнными SHA-256. Новые исходные изображения и карта раскрытия в пакет
не добавляются. Неожиданный файл/каталог, symlink, подмена байтов, отсутствие
файла или превышение лимита останавливают подготовку.

Локальная конфигурация не задаёт routes, custom domain, secrets или binding
существующего RPC. Публичные `workers.dev`/preview URL выключены. Пользовательского
Worker-кода нет; Wrangler при dry-run создаёт свой стандартный no-op модуль.
В локальном Miniflare harness вместо него стоит модуль с ошибкой при вызове:
маршрутизатор статических Assets не должен его вызывать. Этот тестовый модуль
не входит в кандидат.

Шесть сценариев реального локального workerd проверяют страницы и редиректы,
байты публичных ресурсов, MIME JavaScript/CSS/GIF/PNG/WebP/JSON, четыре HTTP-образца
метаданных, отсутствие данных по служебным/приватным адресам, отсутствие RPC/mint
endpoint, `HEAD`, `ETag` и `no-store` для config.js. Все 10000 метаданных до этого
проверены по файлам; не заявляются 10000 отдельных HTTP-проверок. Исходящий HTTP
запрещён, реальная сеть Solana не вызывается.

`auto-trailing-slash` отдаёт `/` и `/devnet/`, а `/privacy.html` и `/terms.html`
перенаправляет на `/privacy` и `/terms`. Это проверено и не меняет содержимое
страниц. Несуществующий JSON получает 404, не HTML главной страницы. `_headers`
задаёт корректные MIME-предосторожности, запрет кэширования config.js и публичный
доступ к чтению метаданных. Кошельки не ограничиваются новыми COOP/CSP-заголовками.

## Выбор и стоимость

Публичные источники и параметры сохранены в [references.json](references.json),
проверены 23 сентября 2026. Фактические счета аккаунтов не запрашивались.

| Вариант | Справочная цена | Значение для CoolBears |
| --- | --- | --- |
| Workers Static Assets | $0 за статическую часть | 20000 файлов и 25 MiB на файл; текущий пакет укладывается с запасом |
| Cloudflare Pages | Статические запросы также бесплатны | Альтернатива того же провайдера; для нового варианта выбран Workers Static Assets |
| Netlify | $0 / $9 / от $20 в месяц | 300 / 1000 / от 3000 кредитов; трафик, запросы и production deployments расходуют общий лимит |
| Нынешний GitHub Pages | Текущая площадка | Ограничения на сайты для коммерческих транзакций делают её неподтверждённым вариантом запуска продаж |

В опубликованных условиях Cloudflare не найдено аналогичного общего запрета
коммерческого использования; Developer Platform прямо предусматривает хостинг
контента. Это основание для выбора кандидата, не индивидуальное одобрение
проекта провайдером. Действуют его условия и лимиты. Бесплатное обслуживание
статических Assets не означает бесплатность произвольного Worker-кода,
RPC-запросов или гарантию неизменных тарифов.

Для Netlify примеры, без прогноза посещаемости: четыре production deployments,
10 GB и 10000 web requests дают 262 кредита; четыре deployments, 100 GB и
100000 requests — 2080. В расчёте 15 кредитов за deployment, 20 за GB и 2 за
10000 запросов. Добавочные сервисы и налоги исключены.

Условное добавление $0 статического хостинга сохраняет сценарии PR27
Pinata/Helius/Workers **$20/$69/$74 в месяц**. Это не итоговый счёт: фактические
тарифы, хранение оригинальной коллекции, трафик, домен, налоги и превышения
ещё неизвестны. Размер этого сайта **11,15 MB не является размером 10000
финальных PNG**. История не содержит подтверждённого общего размера исходной
коллекции; подставлять размер сайта вместо неё нельзя.

## Домен и RPC: конкретное условие переноса

Публичное чтение DNS 23 сентября показало nameservers Porkbun и A/CNAME текущего
GitHub Pages. Custom Domain у Workers требует активную Cloudflare zone. Поэтому
предлагаемый перенос затрагивает **DNS домена**, а наличие нынешнего RPC Worker
само по себе не означает готовность зоны. Только NS/A/www-CNAME проверены;
это не полный экспорт DNS и не проверка DNSSEC. Домен остаётся зарегистрированным
у нынешнего регистратора; перенос регистрации для этой схемы не требуется.

Сайт и скрытые метаданные должны сохранить адрес `https://coolbears-nfts.com`.
В существующем RPC разрешён ровно этот Origin. Временный `workers.dev`, `pages.dev`
или `www` не заменяет его и не считается тестом кошелька. Расширять CORS ради
предпросмотра не нужно: локально проверяется статика, сетевой путь проверяется
позже под утверждённым доменом. Отдельно остаётся production RPC для новой
коллекции: нынешний relay ограничен завершённой лабораторией и перенос сайта
сам по себе этот этап не решает.

## План переноса после выбора владельца

1. Зафиксировать конкретный проверенный commit и пакет, подтвердить аккаунт
   Cloudflare и имя нового сайта. Получить полный снимок текущей DNS-зоны,
   включая MX/TXT/CAA/AAAA и состояние DNSSEC. Существующие записи Porkbun
   сохранить для возврата; не восстанавливать DNS по неполному публичному снимку.
2. Подготовить Cloudflare zone с теми же действующими записями и согласованным
   DNSSEC-переходом. Существующий Helius/Cloudflare RPC и его secrets не менять.
   Создать отдельный статический сайт из проверенного пакета с закрытыми продажами.
3. Сначала проверить временный адрес только как статический сайт: страницы,
   GIF, JSON, заголовки и 404. Домен пока обслуживает прежняя площадка. Это
   предполагает отдельное включение preview/публикации в согласованной конфигурации.
4. После подготовки зоны и проверки выполнить согласованное переключение DNS
   и Custom Domain. Учесть конфликт существующего CNAME, сертификат и канонический
   apex/www. После переключения проверить HTTPS и точные URL скрытых метаданных
   на прежнем домене, затем только read-only состояние RPC с нужным Origin.
5. При несовпадении вернуть сохранённые DNS/маршруты прежней закрытой площадки.
   Данные браузера, лаборатории и блокчейна не очищать. Продажи не открываются
   ни переносом, ни возвратом; снятие AddressGate — отдельный будущий этап.

Сейчас шаги переноса не выполнялись. `readyForDeployment=false`: нет проверки
аккаунта/зоны, TLS и публичного domain routing. Действующая инструкция проекта
пока закрепляет GitHub Pages; переход на другую площадку и изменение DNS
должны быть отдельно согласованы по этому конкретному плану.
